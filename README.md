# SkyTrack para Windows

Aquí se publican las versiones de SkyTrack, el mapa en directo de tus vuelos en
Microsoft Flight Simulator 2024. El código no está en este repositorio: solo el
instalador y lo que la app necesita para actualizarse sola.

**[Descargar la última versión](https://github.com/jespinosa19/skytrack-releases/releases/latest/download/SkyTrack-instalador.exe)**
(Windows 10 y 11, 64 bits)

Doble clic y listo, sin permisos de administrador. Si Windows avisa con «Windows
protegió tu PC», pulsa «Más información» y «Ejecutar de todas formas»: avisa de
todo programa con pocas descargas.

Una vez instalada, la app se actualiza sola: baja la versión nueva en segundo
plano y la instala la próxima vez que la cierras, nunca a mitad de un vuelo.

SkyTrack no está afiliado a Microsoft ni a Asobo Studio.
